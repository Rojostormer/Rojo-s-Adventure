# The Adventurers Guild — Reimagined Prototype

A fan-made offline browser prototype inspired by surviving documentation about TAG.

## Play
Open `index.html` in Safari or any modern browser.

## Implemented
- Guildtown-style hub
- Character/profile screen
- Level and stat progression
- F/E/D-rank quest progression
- Patrol, gathering, escort and boss contracts
- Deterministic-ish turn combat
- Gold, XP, Rank Points and energy
- Five recovered professions: Adventurer, Caster, Defender, Fighter, Rogue
- Profession XP and level 1–10 mastery
- Equipment and inventory
- Local save/export/reset
- Mobile-first UI

## Important
This is a clean-room fan prototype. It does not connect to TAG's former servers, WAX, NFTs, or original backend/assets.
